# PlayMyDisk

Оффлайн-аудиоплеер для iPhone: своя музыка и аудиокниги из файлов, без подписок и интернета.
*(English version below.)*

## Что нужно для установки

- iPhone с iOS 26 или новее
- Компьютер с Windows 10/11 или Mac
- Кабель USB
- Apple ID (подойдёт обычный бесплатный)

## Установка по шагам (Windows)

1. Скачайте файл **PlayMyDisk.ipa** со страницы [Releases](../../releases/latest).
2. Установите **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store):
   - iTunes: https://www.apple.com/itunes/download/win64
   - iCloud: ссылка есть на сайте https://sideloadly.io
3. Перезагрузите компьютер и установите **Sideloadly**: https://sideloadly.io
4. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
5. В Sideloadly перетащите `PlayMyDisk.ipa` на значок IPA, введите свой Apple ID и нажмите **Start**. Пароль Apple ID передаётся только на серверы Apple.
6. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** — включите, телефон перезагрузится.
7. На iPhone: **Настройки → Основные → VPN и управление устройством** — нажмите на свой Apple ID и выберите «Доверять».
8. Запустите PlayMyDisk.

## Важно

- С бесплатным Apple ID приложение работает **7 дней**. Потом повторите шаг 5 — ставьте **поверх**, не удаляя приложение с телефона, иначе пропадут музыка, плейлисты и настройки.
- С бесплатным Apple ID можно держать не больше 3 таких приложений одновременно.

## Как добавить музыку

- Кнопка **+** в приложении — выбор файлов из «Файлов», iCloud Drive и других облаков.
- Приложение «Файлы» → «На iPhone» → папка **PlayMyDisk** — можно копировать музыку прямо туда.
- В любом приложении: «Поделиться» → «Открыть в PlayMyDisk».

Поддерживаются: MP3, AAC, M4A (включая ALAC), M4B, M4R, FLAC, WAV, AIFF, CAF.
Защищённые файлы (.m4p, .aa, .aax) добавить можно, но воспроизвести нельзя — это ограничение их защиты.

# PlayMyDisk (English)

An offline audio player for iPhone: your own music and audiobooks from files, no subscriptions, no internet.

## Requirements

- iPhone running iOS 26 or later
- A Windows 10/11 PC or a Mac
- A USB cable
- An Apple ID (a regular free one is fine)

## Installation (Windows)

1. Download **PlayMyDisk.ipa** from the [Releases](../../releases/latest) page.
2. Install **iTunes** and **iCloud** from Apple's website (not from the Microsoft Store):
   - iTunes: https://www.apple.com/itunes/download/win64
   - iCloud: the link is on https://sideloadly.io
3. Restart the PC and install **Sideloadly**: https://sideloadly.io
4. Connect the iPhone with a cable, unlock it and tap "Trust This Computer".
5. In Sideloadly, drag `PlayMyDisk.ipa` onto the IPA icon, enter your Apple ID and press **Start**. Your Apple ID password is sent to Apple's servers only.
6. On the iPhone: **Settings → Privacy & Security → Developer Mode** — turn it on; the phone will restart.
7. On the iPhone: **Settings → General → VPN & Device Management** — tap your Apple ID and choose "Trust".
8. Open PlayMyDisk.

## Good to know

- With a free Apple ID the app works for **7 days**. After that repeat step 5 — install **over** the existing app without deleting it, otherwise your music, playlists and settings are lost.
- A free Apple ID allows up to 3 sideloaded apps at a time.

## Adding music

- The **+** button in the app picks files from Files, iCloud Drive and other cloud providers.
- Files app → "On My iPhone" → **PlayMyDisk** folder — copy music straight there.
- In any app: Share → "Open in PlayMyDisk".

Supported: MP3, AAC, M4A (including ALAC), M4B, M4R, FLAC, WAV, AIFF, CAF.
Protected files (.m4p, .aa, .aax) can be added but cannot be played because of their DRM.
