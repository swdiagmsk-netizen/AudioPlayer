# PlayMyDisk — что нового

Свежие изменения — сверху. Текст первого раздела автоматически попадает в описание релиза на GitHub.

## 22.11.2026

**По-русски**
- Поиск по списку стал удобнее: пока курсор в поиске, панель плеера сжимается до ряда кнопок, вкладки остаются на месте.
- Найденная строка встаёт третьей сверху и не прячется под клавиатурой.
- Рядом с поиском — кнопки ▲ ▼ для перехода по совпадениям и «Готово». «Ввод» прячет клавиатуру, клавиатура уходит и если потянуть список пальцем.
- Двойное касание строки поиска или крестик очищают её. Касание поля ставит курсор в конец текста.
- Переход на другую вкладку во время поиска очищает строку и подсвечивает трек, игравший в этой вкладке последним.
- Выбор визуализатора (столбики, стрелки, линии) перенесён в «Скин плеера» и появляется только у скина «Классика» — у остальных скинов визуализатора нет.

**In English**
- Easier list search: while typing, the player panel shrinks to the control row; tabs stay visible.
- The found row is placed third from the top, so the keyboard doesn't cover it.
- ▲ ▼ buttons to move between matches and a Done button next to the search field. Return or dragging the list hides the keyboard.
- Double-tap the search field or tap ✕ to clear it. Tapping the field puts the cursor at the end.
- Switching tabs during a search clears it and highlights the track last played in that tab.
- The visualizer choice (bars, needles, lines) moved under “Player skin” and appears only for the Classic skin.

## 17.11.2026 — первая полная версия

**По-русски**
- Плеер без интернета: MP3, AAC, M4A/ALAC, M4B, FLAC, WAV, AIFF, CAF; плейлисты, папки, ★ хит-парад, ♥ «Супер!», честный случайный порядок.
- Экран блокировки: обложка, перемотка ±N секунд или переключение треков.
- Эквалайзер на 10 полос, выравнивание громкости, плавное затухание, таймер сна.
- Аудиокниги: запоминание места, закладки, главы.
- Редактор тегов с записью в файл, поиск дубликатов, отправка файла по почте, импорт с компьютера по Wi-Fi.
- Распознавание песни через микрофон (если доступно при бесплатной подписи), с запасным вариантом и буфером без сети.
- Кнопка «Распознать песню» для экрана блокировки и Пункта управления.
- 12 языков интерфейса, язык берётся как у iPhone.

**In English**
- Offline player: MP3, AAC, M4A/ALAC, M4B, FLAC, WAV, AIFF, CAF; playlists, folders, ★ hit parade, ♥ “Super!”, true shuffle.
- Lock Screen: cover art, ±N second skip or track switching.
- 10-band equalizer, volume leveling, fade-out, sleep timer.
- Audiobooks: position memory, bookmarks, chapters.
- Tag editor that writes to files, duplicate finder, send a file by email, Wi-Fi import from a computer.
- Song recognition via the microphone (if available with free signing), with a fallback and an offline buffer.
- “Recognize song” button for the Lock Screen and Control Center.
- 12 interface languages; the iPhone language is used by default.
